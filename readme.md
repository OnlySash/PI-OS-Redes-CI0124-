## Requisitos para compilar
- C++ compiler
- g++
- make

## Compilación
Utilice las funcionalidades del Makefile como: 
- make: Compilación inicial
- make _____: Compilación de funcionalidades específicas según instrucciones
- make clean: Eliminar archivos creados para compilación
